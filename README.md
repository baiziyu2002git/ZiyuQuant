# 无尽前海 · ZiyuQuant

这是我用来看 A 股、读研报和试因子的工作台。我想回答的问题都挺具体：一个指标过去有用吗？两个好看的因子，买的是不是同一批股票？回测说该买，那天真的买得进吗？

**为什么叫「无尽前海」？** 拉丁语 *infinitus* 意为「无尽」。我现在在深圳，前海是深圳的一个核心区域，就借了它的名字。「无尽」说的是总有问题值得继续研究，「前海」记的是我做这个工作台的地方。

### 因子图谱

手里已经有几个因子时，这页帮你判断：新加的那个到底补了什么？

- 选股票池、看单个因子的历史成绩，再找表现相似的因子。名字不同，不代表提供的是两份不同的信息。
- 切到「组合覆盖」，用八轴雷达查看组合在哪些维度有研究证据。点选一根轴，能分别查成员的归因份额，以及移除某个成员后这一维会损失多少。

### 因子挖掘

从一篇研报找到值得验证的因子，也能回头查清它究竟出自哪段原文。

- 可以导入研报或按任务收集原文。一篇报告可有多个候选；逐个打开，能对照原文摘录、因子定义和清晰度评价，查看本地需要的字段是否齐全。
- 先看验证结果，再选择股票池做正式回测。可以按 IC、Rank IC 等指标调整门槛，达标的排在前面；正式成绩、是否入库、没跑通的原因分开记录。

### 因子研究

单独检验一个因子：它给股票排出的顺序，和后面的收益有没有关系？

- 选因子、股票池、日期与评价频率，设置是否中性化，也可查看本次用的因子源码。结果区可以沿时间查看 IC、Rank IC，判断平均成绩是否只靠少数几天撑起来。
- 分层收益可以逐组比较；行业暴露和风格归因则用来追问，这个因子是不是总偏向某类股票。页面明确区分中性化前的行业暴露和按所选设置完成的回测。

### 因子大全

当问题从「这个因子怎样」变成「这一批里值得细看的有哪些」，就来这里。

- 可以搜因子名，按因子库、股票池、频率和状态筛选，查看匹配的历史成绩；日频不拿周频补，没测过的也不当作零。
- 选好一批后可以运行研究。结果区逐项列出成绩，并汇总本批完成数、失败数和平均指标；还可看横向比较、覆盖情况和任务日志，区分正式完成、仅验证通过和跳过。

### 因子进化

从已经研究过的原因子出发，保留原版，另建候选来试改动。

- 先看父因子的诊断，再选择生成方式。支持通过 API 生成，也可以导出任务、在外部完成后导回候选；每轮候选分别保留。
- 在同一批可比样本上对照父子成绩，查看变化、约束和相似度证据，再决定哪个值得保留。生成了候选和候选通过回测，是两件事。

### 模型研究

用一组因子训练模型，重点看模型在没见过的行情上表现如何。

- 选择输入因子、股票池、预测目标和训练区间，再选模型并单独调它的参数。线性、树和神经网络模型可以共用实验条件；输入因子是否做行业与市值中性化也可选。
- 训练后查看样本外 IC、Rank IC 和预测覆盖；可对照已保存的运行，查看置换检验与正负因子贡献。满意的预测可交给策略回测，不用在策略页重训。

### 策略回测

把预测或策略放进历史行情，关注的不只是哪天净值创新高，还有那笔单到底成交了没有。

- 可以接入模型研究已经保存的预测，查看策略净值、基准、相对收益、年化收益和最大回撤，并按时间区间观察曲线。
- 遇到曲线拐点，可对照历史持仓、委托和实际成交。下方片段展示的是尚未载入结果的页面，不是一次有收益的回测。

### 模拟验证

让策略在独立的模拟账本里逐日推进。它跟踪账户变化，不是真实券商交易。

- 可以切换模拟账户，查看净值、累计收益、超额收益和回撤，按近 20 日、近 40 日或自选区间与基准比较。
- 明日预单、委托和成交分别留账。可以翻历史持仓、对预单、查运行日志，分清是策略没发单、发单未成，还是已经成交。

### 市场情绪

- 除了概览，还可以翻因子拆解、持仓与龙头、估值与财务，并查看数据来源和限制。看旧报告时，能分清报告日期和底层资料的截止日。

### 历史行情

查一只股票某天怎么走，也核对手头这份行情究竟更新到了哪天。

- 下载进度和行情展示分开：可以继续补下载、暂停或只处理一批。单只证券的最新日期与全池完整截止日分别显示，不能拿一只股票更新了当作全市场都齐了。

## 两个我自己踩过的坑

**同样叫周频，收益算到哪天？** 下一周第一个交易日，和今天往后数五个交易日，碰上长假就不再是同一天。下面保留原实验的数字。

信号期间为 **2023-01-01 → 2025-12-31**，实际包含 727 个交易日。股票池来自历史沪深300动态成分；沿用 300 个交易日预热，以及 MAD 3 倍阈值 → 市值／行业中性化 → Z-score。每个截面至少 10 个有效样本；两组分别对共同有效周序列做 1%／99% 线性分位缩尾后求均值。IC 不扣费用，也不在本项试验中运行分层、订单或账户回放。因子输入止于研究末日，之后的行情只用于完成收益标签。

三年共有 154 个周频信号日：130 个恰好相隔五个交易日，21 个只相隔一至四个交易日，另有 3 个因下一自然周整周休市而没有现行周标签。主表只比较共同有效的 **151 周、45,298 个股票—周记录**，每一周两组使用相同股票；不把五日组额外可评的 900 条记录混进均值对比。
