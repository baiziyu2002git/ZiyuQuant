# ZiyuQuant · 子瑜量研

> 先把账算对，再谈收益。

这是我给自己做的一套本地 A 股量化研究工作台。从因子定义、单因子研究，到策略回测、模拟账户，再到候选进化和证据核对，尽量放在一个地方。

做着做着，最费时间的往往不是再写一个因子，而是回答：**这个提升到底从哪来的？跟父因子比的是不是同一段样本？那笔单真的能成交吗？** 如果最后只剩一条漂亮净值线，这些问题就很难追了。

所以我更想把它做成一个能回头对账的研究台，而不是“点一下，财富自由”的许愿机。

## 这段时间主要更新了什么

- **因子进化**：围绕冻结的目标、约束和样本边界迭代候选，支持多轮研究、任务包导出和响应导入。第几轮的候选，就在第几轮里看，不再混着猜。
- **父子对照**：候选得分、主目标增量、约束、相似度和证据条件分开显示。分数高，不自动等于比父因子进步了。
- **相似度与审计**：接入真实公式 AST 映射、原始值／处理值 Pearson 和机制自评；未来信息抽样保留原历史与预热。缺项就明确缺项，不凑一个综合分。
- **复用已有研究**：父面板缺失时，先按冻结身份恢复；确需补算的，先确认预算。能够认证复用的候选结果不因为缺一个父面板就整套重跑。
- **模拟验证与界面**：完整账户数据收进四列两行面板，整理净值、基准、回撤点和双端时间窗口；保留数字首显／展开计数，支持减少动态效果。市场情绪默认看情绪，趋势按需打开。

这些介绍按 2026 年 10 月的本地安装代码与功能记录核对。下面的新图是**交互设计预览**，不是正式 App 的回测截图，两者不混着算。

## 因子进化：生成一个候选，不等于接受它

这一块是相对旧展示页新增的重点。先固定父因子、股票池、期间、处理配置、目标与约束，再做候选生成、评价、审计和对照。不是看见一个高分就一路绿灯。

我把几个容易混淆的东西拆开了：

| 看什么 | 它回答的问题 |
| --- | --- |
| 候选得分 | 这个候选在既定评价口径下表现如何？ |
| 主目标增量 | 在同段共同有效样本、原评价器下，相比父因子改善了多少？ |
| 约束 | 冻结的限制有没有满足？没有计算或没有覆盖，也要单独说。 |
| 因子相似度 | 公式结构、实际逐股输出、机制解释分别有多像？ |
| 证据条件 | 哪些检查有证据，哪些仍然没有？ |

AST 绑定实际表达式与源码／算子版本，不拿公共包装函数当公式。Pearson 按同日共同有限股票计算，保留正负号，原始值和处理值分开看，不把所有日期摊成一长列，也不用 IC 曲线顶替因子值。机制自评仍保留人工复核标识。

多轮任务包会复用严格同身份的公共证据，避免把同一份父数据反复塞进去；已有结果和冻结记录也不会被新一轮悄悄覆盖。

说白了：**像不像、有没有改善、约束过不过、证据够不够，是四件事。**

## 我理解的“高精度回测”，先从日期算对开始

这里的“精度”不是多显示几位小数，更不是预测收益更准。它首先意味着：该用哪一天的价格，就确实用哪一天；没有，就承认没有。

举个假设例子：周频研究约定比较**本周一收盘到下周一收盘**。A 股票周一 100 元、周二 103 元，此后停牌，而下周一也缺少有效端点报价。

- 如果把这一段仅有的日收益跳过缺值后累乘，可能算出 `+3%`。数字没报错，但算到的其实是周二，不是下周一。
- 严格端点标签应为 `P(下周一) / P(本周一) - 1`。下周一缺有效价格，这个样本就暂不能评价，不能拿周二冒名顶替。
- 如果下周一有了同口径的有效价格，例如 101 元，才得到这段区间的 `+1%`。

**累乘本身不是原罪。** 日期完整、价格和收益口径一致时，它与端点相除可以等价。真正坑人的，是跳过缺值、拿上一条记录顶上，最后还把它叫作原来的区间。遇上节假日，也要先按市场交易日历确定约定端点，不能让每只股票自行“往后数几条”。

研究标签和账户估值还得分开：停牌持仓可能按明确规则保留估值，但有估值不等于能成交，更不能反过来补造一个收益标签。

## 从一条信号，追到一笔订单

策略回测保留脚本、净值、基准、回撤及执行记录。研究价格和账户成交／估值各有各的用途，不为了让曲线顺眼就混用。

模拟验证有三个隔离账户，继续区分信号日、明日预单、正式订单、成交、持仓和日志。停牌、涨跌停、整手、现金、费用这些约束，该影响成交时就得影响，不能在看收益时当它们不存在。

净值变了，可以继续查当时的持仓和订单；预单没成交，也应该能看到原因。这里都是本地研究与日线延迟回放，不是券商账户，也不发送实盘委托。

因子研究、因子管理、滚动模型研究、历史行情、数据中心和运行历史也仍然在。日频数据驱动的研究里，可以按配置做日／周／月频因子评价；这不代表支持分钟、Tick 或高频交易。

## 有些边界，还是得摆在明面上

未来信息检查现在有独立版本的 **1% 日常抽样**，也保留 **5% 强化抽样**；旧冻结计划不因新增策略而被改写。抽样先确定日期，再用保留原历史、预热和初始化的输入真实重算，不拿缓存输出充数。

但“这次抽样没发现历史变化”，不等于所有数据都完成了独立 PIT 核验。对应结果仍保留：

> 研究证据部分通过：本样本未发现未来依赖；独立 PIT 未核验。

没有正式通过的门禁，不会因为 UI 换了、任务跑完了或文案写得顺了就自动放行。因子族管理与多样性选因子的新增设计也仍是设计，不提前写成上线功能。

这个仓库只放产品介绍、方法说明和展示素材，不上传工程源码、策略包、原始数据、账户数据库或安装包。页面里的历史研究与模拟结果不是实盘业绩，也不构成投资建议。
