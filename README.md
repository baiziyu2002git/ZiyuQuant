## 最近重点一：市场情绪，把“热闹”拆开看

同样是涨，普涨、少数龙头撑场面、成交突然放大，给人的体感完全不同。我想看的不只是指数红没红，而是市场里面发生了什么。

市场走过这么多年，投资者早已形成一些相似的体会：真正的买点，常让人痛到不敢重仓；真正的卖点，又容易让人舒服到不愿离场。这便是量化研究的意义：少一点情绪驱使，多一点证据——于浩瀚中，发现秩序。

市场情绪把三个观察组合放在一张叠加图里：上面看当前指标，左边回看历史报告，右边继续拆因子、持仓与龙头、估值财务，以及数据限制。

## 最近重点二：因子进化，不把“模型说不错”当结论

有了一个父因子，下一步往往不是凭空造新公式，而是问：哪个环节值得改？改完和原来有多像？提升到底来自机制，还是碰巧选到了舒服的样本？

这里先冻结父因子、目标、约束、股票池、日期和处理配置，再迭代候选。既可以走确认后的模型请求，也能导出任务包、导入结构化响应；第几轮的候选，就在第几轮里看。总览、父因子诊断、候选对照、家族图谱、实验记录都围绕同一个实验身份。

我想做的，是让一个已有研究基础的单因子不断归因、进化和迭代，寻找更强的版本；是否真的改善，仍由同口径的研究证据回答。

对照表刻意把几件事拆开：

| 项目 | 关心的事 |
| --- | --- |
| 候选得分 | 候选自己在既定评价器下表现如何 |

| 约束 | 冻结时约好的限制有没有满足 |
| 相似度 | 公式结构、真实逐股输出与机制解释分别有多像 |
| 证据条件 | 哪些检查有证据，哪些仍缺、仍受阻 |

AST 要绑定实际表达式、源码与算子版本；Pearson 按同日共同有限股票算，保留正负号，原始值和处理值分开。

父面板也不是按名字随便找一个：先核冻结身份，能恢复就恢复，确需补算先确认预算，多个候选共用合格父面板。候选已经完成的主研究不会因为补一项对照又整套白跑。

未来信息检查有独立的 **1% 日常抽样**与 **5% 强化抽样**。检查日期先确定，截断未来但保留原历史、预热和初始化，再真实重算。抽样没发现变化，仍然只写：

> 研究证据部分通过：本样本未发现未来依赖；独立 PIT 未核验。

候选高分、约束通过、任务结束、证据齐全、正式接受，是几件不同的事。不会因为一张表看着很绿就自动放行。

## 最近重点三：我理解的“高精度回测”

不是多显示几位小数，而是别把交易里那些不方便的细节省掉。

**收益先认日期，再认价格。** 假设周频标签约定本周一收盘到下周一收盘：A 股周一 100、周二 103，之后停牌，下周一没有有效端点报价。跳过缺值后累乘可能得到 +3%，但算到的其实是周二，不能让它冒充下周一。严格标签应该按约定的两个端点取价，缺哪端就说明缺哪端。这里的端点取价规则用于 IC／Rank IC 收益标签，不改变分层回测独立的持仓、成交与计价规则。

累乘本身没错：序列完整、口径一致时，它和两端相除可以等价。问题是偷偷跳过缺值、拿上一条记录顶上，然后还叫原来的区间收益。账户持仓的停牌估值又是另一件事，不能拿估值规则补造研究标签。

### 三年十因子实测：五日累乘与现行周频 IC 有多大差别？

这次只读复用现有研究主框架的 Qlib158 因子计算器、预处理、收益标签与 `SignalAnalyzer`，不改框架源码或配置文件。先说明一个容易混淆的事实：**该框架当前已经按精确端点计算周频标签，并不是跳过缺价后累乘。**

对照组按完整五个市场交易日计算：`R₅ = ∏(1 + rᵢ) − 1`，其中每一段 `rᵢ = Pᵢ / Pᵢ₋₁ − 1`。需要连续六个有效收盘价，缺任一个就保留空值；不跳缺口、不填价，也不是把五个收益率直接相乘。

两组在同一个周频信号日观察同一份因子，但终点定义不同：

- **现行周频**：本周首个实际交易日收盘 → 下一自然周首个实际交易日收盘；下一自然周整周休市时，按框架现有实现保留空标签。
- **五日累乘**：从信号日收盘起，固定五个后续市场交易日的日收益连乘。节假日前后，它不一定等于自然周端点。

因此，下表是**两种收益窗口定义的敏感性对照，不是证明累乘或端点谁更准确**。

信号期间为 **2023-01-01 → 2025-12-31**，实际包含 727 个交易日。股票池来自历史沪深300动态成分；沿用 300 个交易日预热，以及 MAD 3 倍阈值 → 市值／行业中性化 → Z-score。每个截面至少 10 个有效样本；两组分别对共同有效周序列做 1%／99% 线性分位缩尾后求均值。IC 不扣费用，也不在本项试验中运行分层、订单或账户回放。因子输入止于研究末日，之后的行情只用于完成收益标签。

三年共有 154 个周频信号日：130 个恰好相隔五个交易日，21 个只相隔一至四个交易日，另有 3 个因下一自然周整周休市而没有现行周标签。主表只比较共同有效的 **151 周、45,298 个股票—周记录**，每一周两组使用相同股票；不把五日组额外可评的 900 条记录混进均值对比。

**信号也不等于成交。** 动态成分按当时名单；收盘后生成的信号按对应执行模式落到后续时点；涨停买不进、跌停卖不出，就得进入执行账。费用、停牌、持仓与现金各有规则，受阻原因留下来，不为了画完净值线乱补价。

不同执行模式有不同假设。归一化研究分层不冒充人民币账户；历史事件扩展中的假设退市结算也不冒充真实清算。IC 标签、分层研究、策略账户和模拟账户分开记账，不能偷换。

这次还做了一个只改涨跌停成交条件的对照：2023 年至 2025 年、沪深300动态、10 个预先选定的 Qlib 因子、5 层、每 5 个交易日调仓。信号、预处理、费用、次日收盘执行和事件处理全部一致，只比较涨停能不能买、跌停能不能卖。

Q1 是最高因子值组。下面是三年**累计净收益**，不是年化，也没有按收益挑选方向：
