# 当前安装版实机视频

这些是 macOS 对 ZiyuQuant 窗口的连续静音录屏，不是网页样机，也不是把截图串成视频。录制于 2026-10-19，本机正常安装版 0.4.0。展示已有记录，不在演示中提交研究、API请求、行情更新或重算。

| 视频 | 实际录到的内容 |
| --- | --- |
| [全模块连续导览 · 2 分钟](https://baiziyu2002git.github.io/ZiyuQuant/#tour) | 市场情绪 → 因子进化 → 因子研究 → 因子大全 → 模型研究 → 策略回测 → 模拟验证 → 历史行情 → 数据中心 → 运行历史 → 系统设置，最后回到市场情绪拆解 |
| [市场情绪](https://baiziyu2002git.github.io/ZiyuQuant/#sentiment) | 默认三条情绪曲线；手动显示 A 趋势，顶部数值、图例与曲线同步变化 |
| [因子进化](https://baiziyu2002git.github.io/ZiyuQuant/#evolution) | 已有 VWAP 实验的候选对照、总览与家族图谱；保留 PIT 未核验及阶段限制 |
| [模拟验证](https://baiziyu2002git.github.io/ZiyuQuant/#simulation) | 已有模拟账户、完整数据展开／收起、数字过渡，以及双端时间窗口的实际区间变化 |
| [因子研究与目录](https://baiziyu2002git.github.io/ZiyuQuant/#research) | 已加载历史运行的 IC、分层曲线及因子大全；不是新提交研究的过程 |

以上入口统一打开 GitHub Pages 在线播放器，支持暂停、进度拖动与全屏，不需要先下载。原始 MP4 继续保留在仓库；播放器加载失败时另有重试和备用下载入口。页面照片与模块介绍仍直接展开在仓库首页。

只对录像做常规视频编码与分辨率适配，保留原始时间顺序，不加速、不插帧制造跟手感，不补收益或状态。全模块导览取同一次录屏的连续前 120 秒，只去掉末尾多余停留，没有拼接不同片段。没有录入麦克风／系统音频或其他应用窗口，也不展示工程、模型或策略源码。

模拟账户不发送实盘委托；历史统计与事件结算假设不等于可兑现收益。模型研究未加载结果、历史行情更新失败等页面状态也在首页照实说明。
