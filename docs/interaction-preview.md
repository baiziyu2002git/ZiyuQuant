# 无尽前海 · 实机影像

[全模块总览](../media/current/all-modules-tour.mp4)用同一个窗口连续录制，约 89 秒。从市场情绪和历史行情开始，依次走过十三个模块，中途换为深色。历史成绩和模拟持仓不代表新研究已经成功，也不是实盘业绩。

| 单页专题 | 看什么 |
| --- | --- |
| [因子图谱](../media/current/atlas.mp4) | 先看成员成绩，再看完整八轴雷达；移动、点选雷达轴，看对应维度与贡献。 |
| [市场情绪](../media/current/sentiment.mp4) | 近 3 月、近 6 月、近 1 年、全部；拖动时间轴，慢移鼠标比较三条线。 |
| [历史行情](../media/current/historical-quotes.mp4) | 缩小并平移 K 线窗口，再用「近 252 日」恢复。在这份样本里实际可见 64 个交易日。 |
| [模拟验证](../media/current/simulation.mp4) | 近 20 日、近 40 日、全部；自定义区间后，沿模拟策略和基准走势查读数。 |
| [模型研究](../media/current/model.mp4) | 对照同一天的样本外 IC 和 Rank IC，观察悬停线条的强调效果。 |

配乐：[《Tears in Rain》](https://www.scottbuckley.com.au/library/tears-in-rain/) · Scott Buckley，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。各片选取不同片段，调整了音量并作淡入淡出；视频字幕以黑底白字叠在窗口内，截图不带字幕，无配音。
