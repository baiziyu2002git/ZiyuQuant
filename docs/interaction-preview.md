# 无尽前海 · 实机影像

[全模块总览](../media/current/all-modules-tour.mp4)用同一个窗口连续录制，约 89 秒。按侧栏顺序浏览十三个模块，中途换为深色。各页展示的是录制时的真实状态，画面里的研究设置、历史成绩和模拟持仓不代表新研究已经成功，也不是实盘业绩。

| 单页专题 | 看什么 |
| --- | --- |
| [因子图谱](../media/current/atlas.mp4) | 选中不同因子，看指标与分层结果如何变化。 |
| [市场情绪](../media/current/sentiment.mp4) | 同一份报告，换不同的历史区间看走势。 |
| [历史行情](../media/current/historical-quotes.mp4) | 对着中信建投的日线看价格、量和副图。 |

每支视频都有普通话旁白。配乐：[Tears in Rain — Scott Buckley](https://www.scottbuckley.com.au/library/tears-in-rain/)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，节选、调音并与旁白混合。
