# 当前安装版实机视频

这些是 macOS 对 ZiyuQuant 窗口的连续静音录屏，不是网页样机，也不是把截图串成视频。录制于 2026-10-19，本机正常安装版 0.4.0。展示已有记录，不在演示中提交研究、API请求、行情更新或重算。

| 视频 | 实际录到的内容 |
| --- | --- |
| [市场情绪](../media/current/market-sentiment-demo.mp4) | 默认三条情绪曲线；手动显示 A 趋势，顶部数值、图例与曲线同步变化 |
| [因子进化](../media/current/factor-evolution-demo.mp4) | 已有 VWAP 实验的候选对照、总览与家族图谱；保留 PIT 未核验及阶段限制 |
| [模拟验证](../media/current/simulation-demo.mp4) | 已有模拟账户、完整数据展开／收起、数字过渡，以及双端时间窗口的实际区间变化 |
| [因子研究与目录](../media/current/factor-research-demo.mp4) | 已加载历史运行的 IC、分层曲线及因子大全；不是新提交研究的过程 |

点击链接查看或下载 MP4；GitHub 不同客户端的播放器支持可能不同。页面照片与模块介绍直接展开在首页，视频不是把其他模块藏起来的入口。

只对录像做常规视频编码与分辨率适配，保留原始时间顺序，不加速、不插帧制造跟手感，不补收益或状态。没有录入麦克风／系统音频或其他应用窗口，也不展示工程、模型或策略源码。

模拟账户不发送实盘委托；历史统计与事件结算假设不等于可兑现收益。模型研究未加载结果、历史行情更新失败等页面状态也在首页照实说明。
