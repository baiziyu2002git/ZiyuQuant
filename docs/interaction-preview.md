# 无尽前海 · 实机影像

| 单页专题 | 看什么 |
| --- | --- |
| [因子图谱](../media/current/atlas.mp4) | 先看成员成绩，再看完整八轴雷达；移动、点选雷达轴，看对应维度与贡献。 |
| [市场情绪](../media/current/sentiment.mp4) | 近 3 月、近 6 月、近 1 年、全部；拖动时间轴，慢移鼠标比较三条线。 |
| [历史行情](../media/current/historical-quotes.mp4) | 缩小并平移 K 线窗口，再用「近 252 日」恢复。在这份样本里实际可见 64 个交易日。 |
| [模拟验证](../media/current/simulation.mp4) | 近 20 日、近 40 日、全部；自定义区间后，沿模拟策略和基准走势查读数。 |
