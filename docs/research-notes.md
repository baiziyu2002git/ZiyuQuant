# 账得一项项对：回测口径与十因子实测

我现在更愿意先看日期、价格和样本身份，再看最终收益。不是收益不重要，而是前面几步错了，后面的小数位再多也没用。

这页讲的是 ZiyuQuant 已有研究路径的口径与实现取舍，不是源码，不是新一轮回测认证，也不是“已经解决全部偏差”的宣言。

## 这次实测：只动涨跌停成交条件，收益会差多少？

不是把一个无约束回测和一个含手续费、次日成交的账户拿来硬比。那样改了好几件事，差多少也说不清是谁的锅。

本次在内存里重新计算十个预先选定的 Qlib 特征，同一份信号分别回放两次。唯一变量是：取消或保留已有分类器明确标记的「涨停不买／跌停不卖」。停牌、缺价、未知状态、缺官方限价保护和公司事件规则都不动，不把受阻股票直接删出股票池。

有个不能省略的插曲：最初用无合成处置的严格模式，首个因子在 2025-03-04 的 600837.SH 持仓上缺少可靠估值而停止，实际返回码 1。没有填价、删股票或把失败表当结果。最终两组都采用 App 已有的历史事件扩展模式：已核验的暂停／换股按其规则处理，其他终止状态含最后记录价的假设结算。**这是研究假设，不是真实清算，也不是独立 PIT 核验通过。**

归一化研究模式不启用人民币最低佣金、整手约束或旧版日频风险退出队列。不能把这张表当作券商实盘可成交收益，也不能用它替代账户级回测。界面截图里的历史父因子／策略结果是另外的已有运行，不是本次十因子对照的曲线。

## 1. 收益标签要认日期，不认“下一条”

如果研究约定的是某个市场交易日到下一期信号日，就先确定这一对日期，再按“股票＋日期”取两端同口径价格：

`区间收益 = 约定结束日价格 / 约定开始日价格 - 1`

这里有三个“别顺手”：

- 别顺手按单只股票剩余记录做位移。停牌、上市较晚、缺数据，会让“下一条”不再是约定的市场日期。
- 别顺手把缺失端点前向填充，或跳过缺值后把一个较短区间的收益算到较长区间头上。
- 别顺手把尾部尚未发布的数据当作零收益。未到端点、开始价缺失、结束价缺失，是不同状态。

例如约定周一到下周一，只有周一100、周二103，之后缺少下周一有效端点。跳过缺值的乘积可能返回3%，但它只回答了周一到周二的问题。严格标签应该保留缺失与原因。

如果同口径的有效下周一报价为101，才得到1%。如果完整日收益序列也存在且定义一致，逐日累乘同样可以算对；不应为了强调端点，就把所有累乘都说成错误。

周一只是这个例子的约定。实际端点要服从该次研究的交易日历、频率和信号定义；遇到休市，不能直接套自然日期，也不能只看配置里写着“周频”就默认各条路径完全相同。信号区间、执行区间和展示归一化也不互相替代。

## 2. IC 标签和账户净值，不是一张账

IC／Rank IC 研究在看某个信号对约定区间收益的解释关系。账户回测还要处理订单、成交、费用、现金、整手和持仓估值。

“停牌持仓按规则留着估值”不等于“可以按这个价交易”；研究上的端点标签缺失，也不等于账户的这笔持仓可以直接抹掉。两边应该各自给出规则，再对账，不能为了方便共用一条填充逻辑。

同样，因子在收盘后才完整生成，就不能在研究说明里偷偷把它当作收盘前已知。实际下单／成交时点以对应执行模式为准，不把 IC 预测区间直接当作可实现的成交区间。

## 3. 动态成分，是“当时的池子”

拿今天的沪深300名单回测很多年前，容易把后来胜出的公司预先带回过去。动态股票池应该按历史信号日的成员身份筛选，不能拿当前名单一把梭。

成员身份和历史输入长度也不是同一件事：在某日属于股票池，不代表因子只能看到它入池后的几条记录。回看窗口、预热与递归初始化仍须按原计算引擎的语义保留。

## 4. 跟父因子比，先站到同一块地上

候选自己的研究分数，不应该直接减一个不同日期、不同覆盖的历史父分数，然后叫“增量”。

父子对照使用冻结目标与原评价器，在同段共同有效样本上计算，保留未舍入结果，再负责显示。这样依然不保证候选有效，但至少比较双方没有各挑一块更舒服的样本。

相似度则另算一件事：AST 看结构，Pearson 看同日逐股输出，机制自评看解释。原始值、处理值分开；Pearson 保留方向，不先取绝对值，也不把股票和日期拉平后糊成一个数。缺了某项就不合成，不能默认补成0或100。

父面板缺失时，先找严格同身份的原面板；确需补算，再列计算与资源预算。多个候选可以共用一次合格的父补充面板，但不能拿同名、不同版本的面板凑数。

## 5. 抽样重算，不能把“轻量”理解成“少给历史”

对一个64日回看因子，只给截点附近48日数据，然后得出“无法覆盖”，并没有完成想检查的事情。截点决定的是何时截断未来，不是授权把截点之前的预热一起扔掉。

当前独立日常抽样策略在获准的审计区间内抽取约1%的日期，可选择5%强化策略；离散日期数按策略取整，旧冻结5%记录仍保留。先固定日期和种子，再真实计算完整输入与截断输入。

比较的不只是截点当天一个数，还包括截点及以前的键、NaN／有限掩码、原始值和处理值。股票池、处理配置、历史和初始化保持原语义。批量快路必须先有语义依据；不支持的表达式回退原执行方式，不裁短历史换速度。

完整主回测与抽样审计是两个环节。抽样少的是检查截点，不是把主回测缩成几天；能认证复用的主结果，也不应该每补一项证据就整套重跑。

## 6. 跑完，不等于什么都通过了

进程退出、任务结束、评价覆盖、约束通过、目标改善、证据检查和正式接受，分别有各自的状态。

抽样没有发现历史变化，只能支持该样本范围内的结论。财务公告可见性、历史修订、公司事件等仍有独立 PIT 的核验边界，不能从一次截断测试直接推导“全链路无未来信息”。

所以界面仍明确保留“研究证据部分通过；独立PIT未核验”。这句话不是装饰，也不会因为综合分高或动画播完了就消失。
